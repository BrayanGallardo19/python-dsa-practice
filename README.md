# 🐍 Python DSA Practice

Repositorio de práctica y estudio de Python, organizado por temas, desarrollado como preparación para certificaciones de Python (fundamentos, POO, estructuras de datos, algoritmos y análisis de datos).

---

## 🎯 Objetivo del repositorio

Reunir ejercicios, laboratorios y mini-proyectos resueltos en Python que cubren desde la sintaxis básica del lenguaje hasta programación orientada a objetos, estructuras de datos, algoritmos de búsqueda/ordenación y una primera aproximación a análisis de datos con Pandas.

---

## 🗂️ Estructura del repositorio

### `Python Basics/`
Fundamentos del lenguaje: variables, tipos de datos, listas, tuplas, diccionarios, sets, rangos, bucles, comprensión de listas, funciones (incluyendo lambdas y ámbito), manejo de excepciones (`raise`), módulos, clases básicas, `enumerate`, `zip`, cadenas y expresiones booleanas. Incluye también mini-proyectos aplicados, como:
- `proyectoCertificacion1.py` — gestor de configuraciones (agregar, actualizar, eliminar y ver ajustes de usuario)
- `validadorDatosMedicos.py` — validación y normalización de registros médicos
- `Encriptacion Caesar.py` — cifrado César
- `generador de patrones.py`

### `Python POO/`
Programación orientada a objetos: clases y objetos, encapsulamiento, herencia, polimorfismo, abstracción, getters/setters, name mangling, y ejercicios integradores como `GameCharacters.py` (sistema de personajes con salud, maná y nivel usando `@property`).

### `estructuras de datos lineales/`
Listas enlazadas, tablas hash, tipos de datos abstractos (TDA), anotación Big O y resolución de problemas aplicando estas estructuras.

### `Algoritmos de busqueda y ordenacion/`
Algoritmos clásicos implementados desde cero: búsqueda binaria, búsqueda en profundidad (DFS) y en anchura (BFS), quick sort, selection sort, merge sort (dos versiones), método de bisección, algoritmo de Luhn, cálculo del n-ésimo Fibonacci, Torre de Hanói, el problema de las N reinas, conversión de lista de adyacencia a matriz y cálculo de ruta más corta entre nodos.

### `Analisis de datos/`
`PandasP.ipynb` — notebook introductorio de análisis de datos con Pandas.

---

## 🛠️ Stack

- **Lenguaje:** Python 3
- **Librerías:** Pandas (notebook de análisis de datos)
- **Formato:** scripts `.py` individuales por tema/ejercicio + notebook Jupyter

---

## ▶️ Cómo usar este repositorio

Cada archivo `.py` es independiente y ejecutable por sí solo:

```bash
python "Python Basics/nombre_del_archivo.py"
```

Para el notebook de análisis de datos:

```bash
jupyter notebook "Analisis de datos/PandasP.ipynb"
```
